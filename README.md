# ForkLab

Fork Lab is a fork() process-tree simulator for C.

- **PPWC**: Assignment 06 questions (CSE 3544, Processes in UNIX)
- **DPOS**: Theory Assignment 1, Q5 a–f (CSE 3249, process creation using fork())
- **My Code**: your own programs, saved in the browser

Press **Step through** to run a program one line at a time and watch the process tree grow with each fork().

Live: https://forklab.nandish.dev
